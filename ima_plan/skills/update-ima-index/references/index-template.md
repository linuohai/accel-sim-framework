# INDEX.md 结构模板

Agent 生成 `ima_plan/INDEX.md` 时应遵循以下结构。总行数控制在 **≤300 行**。

---

```markdown
# IMA Prefetch 研究索引

> 自动生成: <YYYY-MM-DD HH:MM> | 由 /update-ima-index 生成

## 研究总体状态

<1 段话（3-5 句）：当前所处阶段、最近完成的工作、下一步计划>

## 各阶段状态

| Phase | 名称 | 状态 | 关键产出 | 最近更新 |
|-------|------|------|----------|----------|
| 01 | <从 01_*.md 提取> | <状态标签> | <主要文件/结论> | <最近修改日期> |
| 02 | ... | ... | ... | ... |
| ... | ... | ... | ... | ... |
| 07 | ... | ... | ... | ... |

状态标签使用: ✅ 完成 | 🔄 进行中 | 📋 计划中 | ⏸️ 暂停

## 关键发现（8-12 条）

1. <量化结论> → `<来源文件路径>`
2. ...
（每条含具体数据，如 miss rate、speedup 等，附文件指针）

## 目录详情

### <子目录名>/
- **状态**: <简述>
- **关键文件**: `file1.md`, `file2.py`
- **数据/脚本**: N 个 .csv, M 个 .py, K 个 .sh
- **最近修改**: <日期>

（每个子目录 4-6 行，按目录名排序）

## 实现阻塞项

从 `05_implementation/v1_implementation_problems.md` 提取：
- [ ] <问题1>
- [ ] <问题2>
- ...

## Insight 清单

从 `07_paper_outline/insight.md` 提取：
1. <insight 标题>
2. ...

## 待解决问题

从各阶段文档的"关键问题"/"待讨论"段落聚合：
- <来源文件>: <问题描述>
- ...
```
