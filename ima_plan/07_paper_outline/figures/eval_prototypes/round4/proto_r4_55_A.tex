%   --------------------------------------------------------------------
%   TOTAL                                   ~2276 B   ≈ 2.3 KB / SM
%
% Implementation note: grasp_config_t in grasp_prefetcher.h matches the above
% (cd_fifo_depth=20, ct_size=32, tt_size=8, ist_ipt_size=64). The default
% prb_capacity=1024 in source is a "Phase 1 large probe" — the paper uses the
% recommended PRB sizing of 32 entries (256 B).
%
% Per-warp equivalent: 2276 B / 64 warps ≈ 35.6 B/warp (paper rounds to ~36 B).
% System-wide: 2276 B × 64 SMs = 145 664 B ≈ 142 KB on SM80_A100.
% Fraction of L1 cache: 2276 B / (128 KB) ≈ 1.7 % per SM.
%
% Comparison baselines (paper §5.6 Table 4):

%   Snake [MICRO'23]  ~0.8 KB / SM    (GPU, ~12 B/warp)
