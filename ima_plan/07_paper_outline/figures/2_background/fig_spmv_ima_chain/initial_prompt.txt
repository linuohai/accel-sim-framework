## Figure Type
Worked Example: Indirect Memory Access (IMA) Pattern Arising from CSR Format in SpMV

## Purpose
Illustrate how the IMA pattern A[B[j]] arises naturally from the CSR
sparse storage format used in SpMV. The figure must make it visually
obvious that:
1. Iteration j walks stride-1 through A_col[]
2. Each A_col[j] value is used as an index into x[]
3. The resulting access pattern on x[] is scattered (NOT stride-1)
This is the root cause of IMA on GPUs.
