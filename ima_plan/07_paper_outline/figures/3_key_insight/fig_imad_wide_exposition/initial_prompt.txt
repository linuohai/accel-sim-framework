## Figure Type
"Key Insight" figure: IMAD.WIDE operand decomposition showing how a single
SASS instruction encodes ALL parameters needed for IMA data prefetch.

## Purpose
Demonstrate that the SASS instruction `IMAD.WIDE` contains four operands
that exactly match the four parameters a prefetcher needs to predict the
data load address:
1. Destination register (output address)
2. Source register for index (data dependency)
3. Scale immediate (element size, compile-time constant)
4. Constant memory operand (data array base pointer, kernel-lifetime constant)

This is the "zero-inference" insight — a prefetcher reading this instruction
at issue stage gets ALL four pieces of information in one observation.
