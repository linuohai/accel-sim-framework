# Architecture Figure Style Specification

> 最近更新: 2026-04-05
> 版本: v5
> 适用范围: §3 Design 章节全部非数据图
> 风格定位: **高饱和高对比学术风** — 实填色块 + 白字 + 黑色描边，深色但饱和度高
> 标杆: DMP Fig 5-10 (HPCA'24)，figure_prompts.md 验证过的配色
> **AI 生图提示词必须使用 `figure_prompts.md` 通用风格约束段（逐字复制）**

---

## 1. 风格总结（一段话版）

GRASP 论文的架构图/流程图采用**实色填充 + 白色文字**的高对比风格。组件用**中性蓝**（存储）和**中性紫**（逻辑）两种填充色区分类型。箭头用**颜色+线型**编码数据路径语义（黑实线=训练、绿虚线=index prefetch、红虚线=data prefetch）。分区用灰色虚线框。无阴影、无渐变、无 3D。全英文。图中不放标题（标题写在 caption 里），不放文字段落解释（解释写在正文里）。图底部放**图例**，解释箭头颜色含义。

## 2. 色板

### 2.1 组件填充色（中性色调，v4 调亮）

| 类别 | 填充色 | 文字色 | 说明 |
|------|--------|--------|------|
| **存储单元** | 饱和蓝 **#2B5EA7** | 白 #FFFFFF | CT, TT, PRB, IST, PQ |
| **逻辑单元** | 饱和紫 **#6C3483** | 白 #FFFFFF | CD, IPU, DPU, ACU, TC |
| **关键步骤** (flowchart) | 琥珀金 **#D4A843** | 白 #FFFFFF | 写表、关键处理 |
| **成功/完成** (flowchart) | 中性绿 **#5AA469** | 白 #FFFFFF | 终态、L1 HIT |
| **外部/既有** | 白色 #FFFFFF | 黑 #2C3E50 | SM, L1, L2 |

### 2.2 辅助色

| 用途 | 颜色 |
|------|------|
| 分组虚线框 | 灰 #BFBFBF, 1.0pt dashed |
| 分组背景 | 极浅灰 #F0F0F0（可选） |
| 默认线条/文字 | 深石墨 #2C3E50 |

### 2.3 箭头语义色

| 路径 | 颜色 | 线型 | 含义 |
|------|------|------|------|
| **训练路径** | 黑 #2C3E50 | **实线** | CD 检测→写 CT/TT |
| **Index prefetch** | 绿 #27AE60 | **虚线** | IPU→PRB→L1→fill 返回 |
| **Data prefetch** | 红 #C0392B | **虚线** | DPU→PQ→L1 |
| **控制/监控** | 灰 #BDC3C7 | **虚线** | TC 监控 MSHR、suppress |

## 3. Box 规范

| 参数 | 值 |
|------|---|
| 圆角 | 4-6pt（所有组件统一） |
| 边框线宽 | 1.0-1.5pt |
| 边框色 | **黑色 #000000**（所有 box 统一黑色描边，增强对比度） |
| 最小高度 | 24pt |
| 最小宽度 | 56pt |
| 间距 | ≥ 10pt |
| 内边距 | 6pt |

### 组件内文字布局

```
┌─────────────────────┐
│        CD            │  ← 缩写, 10pt Bold 白色
│  (Chain Detector)    │  ← 全称, 8pt Regular 白色
└─────────────────────┘
```

## 4. Arrow 规范

| 类型 | 线宽 | 箭头尺寸 |
|------|------|---------|
| 主数据流 | 1.5pt | 三角, 6pt |
| 辅助/控制 | 1.0pt | 三角, 5pt |

**标注**：8pt italic #2C3E50，紧贴箭头中段。水平箭头标注在上方，垂直箭头标注在右侧。

**编号步骤圈**：①②③④⑤，16pt 直径深色圆 + 白色 9pt Bold 数字，放在箭头旁。

## 6. 图的通用构成规则

### 图中只放：
- 组件框 + 箭头 + 标注 + 编号圈
- 分区虚线框 + 区域标签
- **底部图例**（箭头颜色→路径含义的映射）

### 图中不放：
- **标题**（写在 LaTeX caption 里）
- **文字段落解释**（写在正文里，如 "① Chain Detection: CD detects..."）
- **过多的 annotation**（图要 self-contained 但不要变成文字墙）

### 底部图例格式：
```
Legend:
■ Storage    ■ Logic    □ External
── Training path    - - Index prefetch    - - Data prefetch
```
一行排列，7pt 文字，用实际箭头样式+颜色做示例。

## 7. 每类图的 Layout 要点

### 7.1 架构框图 (Fig A)

整体是一个大矩形，上部 ~2/3 是 **SM**，下部 ~1/3 是 **L2 Cache**。

SM 内部左侧是既有组件（Warp Scheduler、Issue Stage、L1 D-Cache），右侧是 **GRASP**（虚线框）。GRASP 内部分 "Chain Detection" 和 "Prefetch Generation" 两个子区。

L1 D-Cache 在 SM 内部（不是 SM 外面）。GRASP prefetcher 也在 SM 内部，与 L1 紧邻。

### 7.2 流程图 (Fig B)

分 Phase 列（左=训练，右=预取），Phase 标签在列顶部。
菱形=判断（紫填充），矩形=处理（金琥珀），圆角矩形=终态（绿）。
右侧可有灰色注释框提供设计理由。

### 7.3 表结构图 (Fig D)

表头：中性蓝 + 白字 Bold。数据行：白底 + 黑字。
SASS 代码：浅灰背景框 + monospace。

### 7.4 时序图 (Fig E)

水平时间轴。上行=baseline（灰条块），下行=GRASP（蓝/绿条块）。
延迟区间用双向箭头 + 数值。

### 7.5 工作实例图 (Fig G)

按 (a)-(f) 步骤排列。SASS 代码浅灰框。"L1 HIT" 用绿高亮。

## 8. 禁止清单

| 禁止 | 替代 |
|------|------|
| 阴影 | 无 |
| 渐变 | 纯色 |
| 3D 效果 | 2D |
| 线条 >2pt | 最大 1.5pt |
| 图内标题 | 写在 caption |
| 图内文字段落 | 写在正文 |
| 中文 | 全英文 |
| 过暗色调 (#2B3A67) | 中性色 (#2B5EA7) |
| >5 种语义色 | 4 主色 + 灰 |

## 9. 快速检查清单

- [ ] 存储=中性蓝 #2B5EA7，逻辑=中性紫 #6C3483？
- [ ] 深色填充上全部白色文字？
- [ ] 零阴影、零渐变？
- [ ] 无图内标题（标题在 caption）？
- [ ] 无图内文字段落解释？
- [ ] 底部有图例（箭头颜色→路径含义）？
- [ ] 箭头语义：黑实线=训练、绿虚线=index PF、红虚线=data PF？
- [ ] 有编号圈 ①②③ 引导阅读？
- [ ] 整体观感：中性、专业、高对比但不阴暗？
